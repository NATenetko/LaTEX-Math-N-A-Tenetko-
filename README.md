# LaTEX Math N.A. Tenetko · 1.6.4

Локальный редактор для превращения статьи или ответа нейросети в оформленный документ, PDF, озвучивание и компактную видеовизуализацию. Математический исходник хранится отдельно от визуального представления: Markdown и MathJax не переписывают LaTeX.

**[Скачать приложение для macOS](https://github.com/NATenetko/LaTEX-Math-N-A-Tenetko-/releases/latest)** · [Изменения](CHANGELOG.md) · [Старая версия 1.3](archive/v1.3/)

В 1.6.4 исправлено обнаруженное расхождение скорости экспорта WAV/MP4 с чтением в приложении: настройки выше 1 больше не вызывают чрезмерного ускорения. Шкала экспорта приведена к шкале Chromium/Electron. LaTeX, Markdown и PDF не изменены; предыдущий релиз 1.6.3 остаётся доступен.

## Возможности

- Вставка текста и формул; поддержка `\(...\)`, `\[...\]`, `$...$` и `$$...$$`.
- Безопасный Markdown: заголовки, выделения, списки, цитаты и код.
- Редактирование формул с сохранением оригинала, аудит SHA-256 и посимвольный round-trip.
- Сохранение и открытие JSON-проектов, копирование текста обратно для ИИ.
- Постраничный PDF A4: классический Times New Roman или современный Arial, без интерфейса приложения, даты и URL.
- Озвучивание системными голосами, выбор места чтения курсором и синхронная визуализация слов.
- Экспорт озвучивания в WAV и небольшого видео в MP4, 960×240.
- Вкладка «Аудио → черновик»: локальное распознавание, добавление результатов без очистки предыдущего текста.
- Последовательная очередь аудиофайлов; сохранение прямо в TXT или в черновик, разделение по 5 000 / 10 000 знаков.

## Готовое приложение для Mac

Скачайте ZIP из Releases, распакуйте и перенесите приложение в «Программы». Сборка 1.6.4 предназначена для Apple Silicon — M1/M2/M3/M4 и других ARM Mac. Сборка для Intel в этом выпуске не предлагается.

Для редактора, формул и PDF не нужны интернет, Node.js или сервер. MathJax включён в приложение. Озвучивание использует доступные системные голоса macOS; отсутствующий голос может потребовать отдельной загрузки средствами macOS.

Сборка имеет локальную ad-hoc подпись, но не Apple-нотарификацию: macOS может потребовать дополнительного подтверждения открытия. Проверяйте источник скачивания; при необходимости используйте предусмотренную macOS процедуру разрешения приложения в настройках безопасности.

### Распознавание аудио — отдельная локальная зависимость

Whisper и его модель **не входят в ZIP**. Распознавание включается только при наличии `whisper-cli` и модели на компьютере. Приложение проверяет Homebrew-пути `/opt/homebrew/bin/whisper-cli` и `/usr/local/bin/whisper-cli`, а путь модели читает из `~/Library/Application Support/Dictation/config.json` (поле `model`, абсолютный путь). Без конфигурации проверяется `Dictation/models/ggml-large-v3-turbo-q5_0.bin` в той же папке Application Support.

Для OGG/Opus необходим установленный FFmpeg; при его наличии он также используется для других аудиоформатов. Модель автоматически не скачивается, аудио в облако не отправляется. Без этих зависимостей редактор и остальные вкладки остаются доступны.

За один выбор разрешено до 100 записей, размер каждой — не более 1 ГиБ. Это ограничение входа, а не гарантия обработки любой длительности: длинные записи требуют свободного места, памяти и времени. Очередь не восстанавливается после закрытия приложения; сохраняйте результаты в TXT.

## Браузерная версия

Скачайте исходники целиком и откройте `index.html`. Не отделяйте HTML от соседних JS/CSS и `mathjax.js`.

Документный редактор работает без интернета. Экспорт PDF использует печать браузера; для A4 выбирайте масштаб 100%, поля «Нет» и отключайте колонтитулы. Озвучивание зависит от браузера и установленных голосов. Нативный экспорт WAV/MP4 и локальное распознавание Whisper доступны в приложении macOS, а не в обычной веб-странице.

Чтобы перенести документ из старой версии, сохраните `.mathdoc.json` и откройте его в новой. Автосохранение браузера в Electron автоматически не переносится.

## Разработка и проверка

Установите Node.js. Из корня проекта:

```bash
npm install
npm test
```

Тесты проверяют сохранность LaTeX, Markdown, чтение, экспортные данные, разделение TXT, повторное сохранение после ошибки и блокировку очереди. Дополнительный тест собственной статьи можно включить переменной `TENETKO_TEST_ARTICLE`; пользовательские статьи в репозиторий не включены.

При подготовке 1.6.4 проверены русская и английская речь при скоростях 0,5 / 0,8 / 1 / 1,5 / 2: расхождение длительности WAV и чтения в тестовых фрагментах составило менее 5% при одинаковом голосе. Проверены реальные MP4 на скоростях 0,5 / 1 / 1,5 / 2 и экспорт через готовую сборку macOS. Это результаты конкретных проверок, не гарантия одинаковой длительности для любого голоса и текста. Для сравнения выбирайте одинаковые голоса чтения и экспорта.

Для запуска приложения из исходников и сборки на macOS нужны инструменты разработки Apple с `swiftc`:

```bash
mkdir -p desktop/bin
swiftc desktop/speech-export.swift -o desktop/bin/speech-export
swiftc desktop/video-export.swift -o desktop/bin/video-export
npm run test:native-rate
npm start
```

Для сборки:

```bash
npm run build:mac
```

Скрипт создаёт `dist/LaTEX Math Tenetko.app` для архитектуры компьютера сборки. Готовые сборки публикуются в Releases, а не хранятся среди исходников.
