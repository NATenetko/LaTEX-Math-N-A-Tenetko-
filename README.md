# AI Math Document Editor

Локальный прототип редактора, в котором математический исходник хранится отдельно от DOM и результата MathJax.

## Безопасный Markdown-слой

Markdown применяется только после того, как математический конечный автомат
заменил формулы защищёнными UUID-токенами. Поддерживаются заголовки H1–H3,
жирный и курсивный текст, списки, цитаты, горизонтальные линии, inline-code и
fenced code blocks. Визуальные delimiters Markdown не попадают в печатное
представление.

Переключатель `Markdown rendering` действует только на новые вставки и новые
`.md`-импорты. В положении OFF текст показывается буквально, но формулы всё
равно извлекаются стабильным LaTeX-сканером и остаются атомарными MathBlock.

Точный исходник нового Markdown-документа хранится в `rawSource` и в
append-only массиве `rawImports`. Уже сохранённые JSON-проекты открываются
напрямую и не проходят повторный Markdown parsing.

## Запуск

Откройте `index.html` в браузере. Приложение и официальный MathJax 3.2.2
находятся в проекте, поэтому после скачивания всей папки формулы работают без
интернета. Документ, raw-снимки и JSON-проекты также остаются локальными.

Не отделяйте `index.html` от `app.js`, `styles.css` и `mathjax.js`.
В автономной сборке используется официальный полный TeX + SVG-компонент;
SVG-режим не требует загрузки веб-шрифтов.

1. Скопируйте ответ ChatGPT, Claude, Gemini или другого сервиса.
2. Нажмите `Cmd+V` / `Ctrl+V` в редакторе либо кнопку «Вставить».
   Помимо стандартных delimiters, импорт безопасно распознаёт повреждённый
   clipboard-формат, где `[` и `]` стоят отдельными строками вместо `\[` и `\]`.
3. Дважды кликните по формуле, чтобы явно изменить только `latexCurrent`.
4. Используйте «Проверить формулы» для SHA-256 и round-trip аудита.
5. «Сохранить» выгружает `.mathdoc.json`; «Открыть» принимает сохранённый проект или файл `.md` / `.markdown`.
   При импорте Markdown приложение сначала защищает точный LaTeX, а затем разбирает
   заголовки, абзацы, жирный и курсивный текст, списки, цитаты, линии и fenced code.
   Исходное содержимое Markdown также сохраняется отдельным raw-снимком.
6. «Копировать для ИИ» сериализует математические строки без нормализации.
7. «Экспорт PDF» ждёт MathJax и открывает системную печать.

Локальная резервная копия текущего проекта также сохраняется в `localStorage` браузера.

## Автоматический тест

```bash
node tests/roundtrip.test.js
```

Тест проверяет обязательные формулы из ТЗ, четыре вида разделителей, fenced
code, inline code, feature flag OFF, Markdown → JSON → Copy → reimport,
escaped dollar, дополнительные регрессионные формулы и стандартный вектор
SHA-256. Контрольные хеши стабильного ядра записаны в
`tests/REGRESSION_BASELINE.md`.

Лицензия локальной копии MathJax сохранена в `MATHJAX-LICENSE.txt`.
